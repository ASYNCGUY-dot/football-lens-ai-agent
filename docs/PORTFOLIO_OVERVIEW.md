# Football Lens | 포트폴리오 안내

## 해결하려는 문제
여러 소스에 흩어진 축구 뉴스와 경기 정보를 한 흐름에서 수집·정리·탐색하고자 했습니다.
수집과 전처리, 여러 LLM의 분석, 대시보드와 과거 기사 검색을 연결한 개인 프로젝트입니다.

## 구현과 역할
Python, LangGraph, LangChain, ChromaDB, Streamlit을 사용했습니다.
뉴스·경기 수집, 상태 기반 그래프, 언어와 작업별 분석, 검색과 화면을 구성했습니다.

## 코드로 확인할 수 있는 역량
- [수집기](../week1/collectors/): 소스별 수집과 외부 API 연동
- [그래프](../week2/graph.py), [상태](../week2/state.py): 파이프라인 상태와 작업 흐름
- [LLM 노드](../week2/llm_nodes.py): 모델 호출과 분석
- [RAG](../week3/rag/): 기사 임베딩과 검색
- [결과 저장](../week3/storage/results_store.py), [대시보드](../week3/dashboard/): 결과 관리와 화면 구성
- [테스트](../tests/): 리그·경기 데이터·검색 전처리 등의 회귀 검증 코드

## 현재 상태와 한계
수집 경로와 사용할 수 있는 모델은 API 키와 외부 서비스에 따라 달라집니다.
README에 제시한 모든 외부 소스의 현재 가용성을 이번 정리에서 재검증하지 않았습니다.
생성한 경기 전망은 실전 예측 정확도가 검증된 모델이라는 의미가 아닙니다.
테스트 파일이 존재하는 것과 이번 세션에서 테스트를 실행한 것은 구분합니다. 이번에는 기능 테스트를 재실행하지 않았습니다.

실행 방법은 [README](../README.md)를 확인해 주세요. 실제 현재 파일 구조는 위 코드 링크를 기준으로 볼 수 있습니다.
